# Home Kitchen Lab

个人自学烹饪知识库。核心方法：**做菜 → 记录 → 复盘 → 改进**。

菜谱讲「怎么做」，原理讲「为什么」，两者双向链接。

## 目录结构

- `菜谱/` — 一道菜一个文件：用料表、步骤、关键点与易错点、复盘记录
- `原理/` — 烹饪背后的物理/化学机制，一个原理一个文件，被菜谱引用
- `笔记/` — 刀工、选材、厨具等经验技巧
- `素材/` — 图片，按菜名分目录

## 工作方法

- 每道菜按固定模板记录：用料表 → 步骤 → 关键点与易错点 → 复盘记录
- 每次实操后在菜谱中追加复盘：调整了什么 → 结果如何 → 下次改什么
- 步骤背后可复用的原理，抽取到 `原理/` 并与菜谱双向链接
- 未实操验证的用量与温度标注「待验证」
